# My First Python Project: Calculator & Base Converter

This is a comprehensive Python program that performs basic mathematical operations and also converts numbers between different bases.

## Features
- Mathematical operations (Addition, Subtraction, Multiplication, Division, and Modulo)
- Convert Binary (Base-2) to Decimal (Base-10)
- Convert Decimal to Binary

## How to run
Just run the calculator.py file in your terminal:
python calculator.py
